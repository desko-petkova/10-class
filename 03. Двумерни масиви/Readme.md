## Многомерни масиви в C#

### 1. Какво е многомерен масив

Многомерният масив представлява съвкупност от елементи от един и същи тип, които се подреждат в повече от едно измерение. Най-често използваният многомерен масив е **двумерният масив**, който може да се разглежда като **таблица с редове и колони**, подобно на математическа матрица.

В C# съществуват два основни вида масиви с повече от едно измерение:

* **правоъгълни (rectangular) многомерни масиви**
* **назъбени (jagged) масиви**

---

# 1. Правоъгълни многомерни масиви

## Двумерен масив

Двумерният масив съдържа елементи, които се достъпват чрез **два индекса** – ред и колона.

Пример за матрица с **2 реда и 3 колони**:

|        |        |        |
| ------ | ------ | ------ |
| m[0,0] | m[0,1] | m[0,2] |
| m[1,0] | m[1,1] | m[1,2] |

В C# индексите на масивите започват от **0** и завършват на **брой елементи – 1**.

---

## Дефиниране на двумерен масив

Общ вид:

```
тип[,] имеНаМасива = new тип[бройРедове, бройКолони];
```

Пример:

```csharp
int rows = 2;
int cols = 3;

double[,] m = new double[rows, cols];
```

По-кратък вариант:

```csharp
double[,] m = new double[2,3];
```

След създаването размерът на масива **не може да се променя**.

---

## Достъп до елемент

Всеки елемент се достъпва чрез два индекса:

```
имеМасив[ред, колона]
```

Пример:

```csharp
m[0,0]
m[1,2]
```

---

## Инициализация при създаване

```csharp
double[,] m =
{
    {1.1, 2.3, -3},
    {4.3, -5.1, 6.4}
};
```

---

## Въвеждане на елементите

Най-често се използва **вложен цикъл**.

```csharp
int[,] m = new int[2,3];

for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 3; j++)
    {
        Console.Write($"Въведете m[{i},{j}] = ");
        m[i,j] = int.Parse(Console.ReadLine());
    }
}
```

---

## Извеждане на двумерен масив

```csharp
for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 3; j++)
    {
        Console.Write(m[i,j] + " ");
    }
    Console.WriteLine();
}
```

# 2. Тримерни и по-високи измерения

Масивите могат да имат **повече от две измерения**.

Пример за тримерен масив:

```
тип[,,] имеМасив = new тип[x,y,z];
```

Пример:

```csharp
int[,,] cube = new int[3,4,2];
```

Достъп до елемент:

```csharp
cube[1,2,0]
```

Обикновено се използват **три вложени цикъла**.

```csharp
for(int i=0;i<3;i++)
    for(int j=0;j<4;j++)
        for(int k=0;k<2;k++)
            cube[i,j,k] = i + j + k;
```

# 3. Назъбени масиви (Jagged Arrays)

Назъбеният масив представлява **масив от масиви**.

Основната разлика е, че **всеки ред може да има различна дължина**.

---

## Дефиниране на назъбен масив

Общ вид:

```
тип[][] имеМасив = new тип[бройРедове][];
```

След това всеки ред се създава отделно.

Пример:

```csharp
int[][] a = new int[3][];

a[0] = new int[2];
a[1] = new int[4];
a[2] = new int[3];
```

Структурата изглежда така:

```
a[0] -> [ , ]
a[1] -> [ , , , ]
a[2] -> [ , , ]
```

---

## Инициализация

```csharp
int[][] a =
{
    new int[] {1,2},
    new int[] {3,4,5,6},
    new int[] {7,8,9}
};
```

---

## Достъп до елемент

```
a[ред][колона]
```

Пример:

```csharp
a[1][2]
```

---

## Въвеждане на назъбен масив

```csharp
for (int i = 0; i < a.Length; i++)
{
    for (int j = 0; j < a[i].Length; j++)
    {
        Console.Write($"a[{i}][{j}] = ");
        a[i][j] = int.Parse(Console.ReadLine());
    }
}
```

---

## Извеждане

```csharp
for (int i = 0; i < a.Length; i++)
{
    for (int j = 0; j < a[i].Length; j++)
    {
        Console.Write(a[i][j] + " ");
    }
    Console.WriteLine();
}
```

---

# 4. Разлика между двумерен и назъбен масив

| Двумерен масив                         | Назъбен масив                            |
| -------------------------------------- | ---------------------------------------- |
| Всички редове имат еднакъв брой колони | Редовете могат да имат различна дължина  |
| int[,] a                               | int[][] a                                |
| a[i,j]                                 | a[i][j]                                  |
| Подходящ за матрици                    | Подходящ за структури с различни размери |

---

Многомерните структури от данни (най-често **многомерни масиви**) се използват когато данните могат естествено да се подредят в **таблица, решетка или пространство с повече от едно измерение**. Те позволяват по-удобно представяне и обработка на такива данни.

## 1. Представяне на таблици и матрици

Най-честото приложение е представянето на **таблични данни**.

Примери:

* оценки на ученици по предмети
* разписание на часовете
* таблици с измервания
* математически матрици

Пример:
Редовете могат да са **ученици**, а колоните **предмети**.

```csharp
int[,] grades = new int[20,5];
```

---

## 2. Работа с изображения

Дигиталните изображения се съхраняват като **матрица от пиксели**.

* ред → позиция по височина
* колона → позиция по ширина

Например черно-бяло изображение:

```csharp
int[,] image = new int[height, width];
```

Цветните изображения често използват **тримерни масиви**:

```csharp
int[,,] image = new int[height, width, 3]; // RGB
```

---

## 3. Игри и игрови полета

Много игри използват **двумерни решетки**.

Примери:

* шах
* судоку
* морски шах
* лабиринти
* карти на игри

Пример за шахматна дъска:

```csharp
char[,] board = new char[8,8];
```

---

## 4. Научни и инженерни изчисления

В науката често се използват **матрици и многомерни масиви**.

Примери:

* линейна алгебра
* статистика
* физични симулации
* машинно обучение

Например матрица за изчисления:

```csharp
double[,] matrix = new double[100,100];
```

---

## 5. Географски данни и карти

Картите могат да се представят като **решетка от клетки**.

Примери:

* височина на терена
* температура по региони
* карти в GIS системи

```csharp
int[,] map = new int[rows, cols];
```

---

## 6. Симулации и моделиране

При симулации на процеси в пространство се използват **3D масиви**.

Примери:

* разпространение на топлина
* симулация на флуиди
* моделиране на материали

```csharp
double[,,] temperature = new double[x,y,z];
```

---

## 7. Назъбени масиви (jagged arrays)

Назъбените масиви се използват когато **размерът на редовете е различен**.

Примери:

* графи (списък на съседство)
* таблици с различен брой стойности
* данни с променлива структура

```csharp
int[][] graph = new int[5][];
```

---

## Обобщение

Многомерните структури от данни се използват когато данните имат **естествена структура в повече от едно измерение**, например:

* таблици
* матрици
* изображения
* игрови полета
* карти
* научни симулации

Те позволяват **по-логично представяне на данните и по-лесни алгоритми за обработка**.
